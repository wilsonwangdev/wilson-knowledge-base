框架决策：继续使用 Quartz

分析时间：2026-05-23 · 更新：2026-05-26（反映简化后的当前状态）
核心结论：Quartz 的知识图谱 + Obsidian 兼容性是核心竞争力，H5 体验通过「最小化定制」优化。

当前定制清单（vs Quartz 默认）

维度 Quartz 默认 本站当前 定制原因
桌面 Explorer 排序 默认排序 固定板块顺序 + 按日期倒序 阅读列表 / 仓库列表两个板块独立，用户按时间浏览
PrevNext 导航 全站连续 板块内连续，跨板块断开 阅读列表和仓库列表是两个独立内容流，不应互串
Backlinks 去重 侧栏 + afterBody 各一份 桌面侧栏显示，移动端 afterBody 显示 避免同一份内容出现两次
Backlinks 标题 "Backlinks" / "反向链接" 重命名为 "关联阅读" 对非技术读者更友好
移动端图谱 显示 隐藏 Canvas/WebGL 在移动端不可交互，浪费渲染资源
移动端页面标题 显示 隐藏 文章标题已在正文中，节省顶部空间
移动端触摸优化 默认 touch-action: manipulation 消除 iOS Safari 双击缩放延迟
移动端 Explorer 溢出 overflow: hidden（会裁剪 drawer） 展开时 overflow: visible 修复移动端 drawer 展开内容被截断的 Quartz bug
移动端文件夹缩进 默认多层缩进 减小缩进 窄屏下多层缩进过大，标题被挤成几个字
桌面 ReaderMode 原生 toggle opacity 隐藏侧栏 + 浮动退出按钮 保留布局占位（不跳动），hover 失效时仍可退出
RSS 内容清洗 原样输出 HTML 剥除锚点 SVG 邮件客户端无法渲染锚点图标
邮件订阅 无 NewsletterFooter inline 表单 静态站点零成本获取订阅者
评论系统 无 Giscus + 暗色模式适配 为读者提供互动渠道
页脚部署时间 仅版本号 部署时间戳 方便确认站点维护状态
主题色 默认紫/灰 蓝色系（自主选择） 视觉偏好，不影响功能
字体 Inter + 等宽 Inter + JetBrains Mono（自托管） 代码阅读更舒适，无 Google Fonts 依赖

被放弃的定制（已回退）

早期版本（2026-05-23 之前）custom.scss 有 230+ 行移动端重写，包括：

  • 自定义 drawer：position: fixed 替代 Quartz 原生 absolute
  • backdrop-blur：手动注入 backdrop 元素 + JS 生命周期管理
  • 关闭按钮：移动端导航面板手动插入 ✕ 按钮
  • cubic-bezier 动画：替换原生 transition
  • 44px 汉堡按钮：自定义触摸目标尺寸
  • SidebarCollapse 组件：独立的桌面侧栏折叠（后被阅读模式替代）

这些定制在 2026-05-23 的审查中被认定为「过度定制」，与 Quartz 原生行为冲突。随后全部回退，回归到上表中 ~15 条最小化修改。

选型结论

评估维度 Quartz 替代方案 (Nextra/VitePress) 结论
知识图谱 D3.js + PixiJS 原生支持 需手动实现或插件 Quartz 胜
Obsidian 兼容 [[wikilinks]]、反向链接、图谱原生 需大量自定义 Quartz 胜
构建速度 ~3s 类似 持平
静态输出 纯 HTML + Vercel 部署 同样支持 持平
H5 体验 原生可用，最小化定制即可 更成熟的开箱体验 略逊，但已通过回退解决
迁移成本 — 需转换所有 wikilinks + frontmatter 高
个人品牌 Digital garden 定位明确 普通文档站 Quartz 更匹配

核心原则

Let Quartz be Quartz。

  • 定制应像补丁，不是重写
  • 只修改有明确痛点的交互，不为改而改
  • 保持升级兼容——删掉 custom.scss 就能回到 Quartz 原生
  • 所有定制都有可追溯的 commit 和文档理由
