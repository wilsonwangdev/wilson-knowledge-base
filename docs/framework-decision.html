被放弃的定制（已回退）

早期版本 custom.scss 有 230+ 行移动端重写，后在审查中被认定为「过度定制」，与 Quartz 原生行为冲突。已全部回退，包括：

  • 自定义 drawer：position: fixed 替代 Quartz 原生 absolute
  • backdrop-blur：手动注入 backdrop 元素 + JS 生命周期管理
  • 关闭按钮：移动端导航面板手动插入 ✕ 按钮
  • cubic-bezier 动画：替换原生 transition
  • 44px 汉堡按钮：自定义触摸目标尺寸
  • SidebarCollapse 组件：独立的桌面侧栏折叠（后被阅读模式替代）

核心原则

Let Quartz be Quartz。

  • 定制应像补丁，不是重写
  • 只修改有明确痛点的交互，不为改而改
  • 保持升级兼容——删掉 custom.scss 就能回到 Quartz 原生
  • 所有定制都有可追溯的 commit 和文档理由
