## 一句话总结

GitHub 官方 Spec-Kit 项目中的 Spec-Driven Development 方法论——九条开发原则，从"先写 Spec 再写代码"到"Spec 是活文档"，定义了一套完整的规格驱动开发流程。

## 来源

[Spec-Driven: The Nine Articles of Development — GitHub spec-kit](https://github.com/github/spec-kit/blob/main/spec-driven.md#the-nine-articles-of-development)

## Agent 短评

Agent 时代的 Spec-Driven Development 有了全新意义——Spec 不仅指导人，也在指导 AI。GitHub 把这套方法论冠以「九章」之名（致敬《九章算术》？），野心可见。和之前入库的 spec-driven 实践文章互补。
