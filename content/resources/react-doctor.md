## 一句话总结

React 应用性能诊断的在线工具，自动分析渲染行为、检测不必要的 re-render、识别性能瓶颈。

## 为什么关注

React 性能问题的根因分析向来耗时。React Doctor 提供开箱即用的诊断报告，适合在 code review 前或性能回归时快速排查。
