## 学习路线

### 前置：理解 Web 如何运作
先理解网络原理（3 个 YouTube 视频），再开始写代码——为后续 API、部署等一切提供上下文。

### 1. HTML + CSS
框架之前，先扎实掌握结构、布局、响应式。目标：能自信地构建简单网页。

### 2. JavaScript
核心概念：变量、函数、数组、对象、异步、DOM 操作。不强 JS，后面都吃力。

### 3. Git + GitHub
早点学版本控制——项目管理和协作离不开，对实习和开源贡献也很重要。

### 4. 后端基础
服务器、API、数据库、认证、REST 概念。先理解后端再学前端的顺序比先冲框架更合理。

### 5. 后端进阶
架构、可扩展性、理论概念——这是"教程跟随者"和"真开发者"的分界线。

### 6. 前端框架（React / Next.js）
后端舒服了再切前端框架，因为已经理解数据如何在应用中流动。

### 7. 构建真实项目并发布
- 克隆真实 App → 按 GitHub 作业做 → 公开部署 → 基于错误迭代
- 项目教会你教程永远教不会的东西

### 8. 写下来
写文章或分享能双向收获：教别人加深理解 + 建立个人品牌。

### 核心理念
全栈不是一次学完所有东西，而是**逐层学习**：Web 原理 → 基础 → 后端 → 框架 → 构建 → 发布。目标不是刷完课程，而是持续创造。
