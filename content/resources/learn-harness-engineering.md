## 一句话总结

一个结构化的 Harness Engineering 在线课程，通过 12 篇理论讲义 + 动手项目 + 可复制模板库，教开发者如何用约束和规则让 AI coding agent（如 Codex、Claude Code）真正可靠地工作。

## 为什么关注

市面上关于 agent harness 的讨论多散落在 OpenAI/Anthropic 的官方博文和推文中，缺乏从「为什么模型会失败」到「如何设计闭环」的完整教学链路。这个课程把 Harness Engineering 当作一门工程学科来教：每篇讲义围绕一个具体问题展开（如「为什么 feature list 是 harness 原语」「为什么端到端测试改变结果」），不是堆砌概念。附带可直接复用的 AGENTS.md、feature_list.json 等模板，实践导向强。
