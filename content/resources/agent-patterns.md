## 一句话总结

Agent 工程领域的权威参考目录——按概念组织的纯 Markdown 知识库，覆盖 Context Engineering、Agent Design、Multi-Agent、Tool Engineering、Verification、Security、Observability 等 20+ 主题，CC BY 4.0 开源，专为 AI Agent 可消费而设计。

## 为什么关注

这不是"教你写 Agent"的教程，而是**按概念组织的参考手册**。每个页面覆盖一个独立概念：是什么、怎么工作、何时用、注意什么。设计哲学是"one concept per file, sourced and self-contained"——极其适合 Agent 消费（可直接加载到上下文中）。

与同类资源的差异：
- **结构化程度**远超零散的博客文章——每个条目遵循统一格式
- **Agent-first 设计**——首页直接写了 "This site is built for AI agents as much as for people"，并提供 `how to use the corpus` 指南
- **开源可克隆**（CC BY 4.0）——整个知识库可以本地化使用
- **跨工具覆盖**——在 Claude Code、GitHub Copilot、Cursor、OpenAI Agents SDK 上展示
- **配套课程**——learn.agentpatterns.ai 提供 164 节动手课程

覆盖的主题目录：
