## 一句话总结

一个跨设计系统的 UX 组件参考平台——可浏览、对比、搜索主流设计系统中的组件规范，附带 W3C ARIA 模式映射、AI 问答和 MCP Server 接口。

## 为什么关注

这不是又一个组件库展示站。它做的是"组件百科"：把 Material Design、Ant Design、Radix、Shadcn 等几十个设计系统中的同名组件并排对比，展示命名差异、状态覆盖、ARIA 实现差异。对于需要跨系统选型或在多个设计语言间做技术决策的工程师来说，这比翻各个文档快得多。

额外亮点：内置 AI 问答（"何时用 tabs 而非 accordion"这类决策问题可以直接问）、通过 MCP Server 让 AI 编码工具直接读取组件数据、以及 DESIGN.md 规范——一份能让 Agent 理解品牌设计约束的声明文件格式。
