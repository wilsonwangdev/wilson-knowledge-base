## 一句话总结

一个可视化 UI 元素词典——每个组件都有截图、正式名称、平台标签（macOS/Web）、CSS/ARIA 代码引用，67 个条目覆盖从 Hamburger Menu 到 Masonry Layout 的全部常见 UI。

## 为什么关注

开发者日常最大的 UI 沟通障碍不是不会做，是不知道那个东西叫什么。搜"那个三个横线的按钮"和搜"Hamburger Menu"返回的结果质量完全不同。这个站解决的就是命名问题——而且不是文字定义，是截图+名称+代码引用的三件套。

特别适合 Agent 编码场景：当你需要向 AI 描述一个 UI 时，从这个站找到精确名称比凭感觉描述有效得多。每个条目还标注了平台归属和 ARIA 属性，直接可以当 accessibility 参考用。另有一个"Name That Vibe"子站覆盖视觉风格命名。
