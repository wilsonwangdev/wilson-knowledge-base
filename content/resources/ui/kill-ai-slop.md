## 一句话总结

一份系统化的 AI Slop 视觉图鉴，逐条拆解 33 种 Vibe Coding 产出的 UI 反模式，每条配 before/after 对照和代码信号检测规则。

## 为什么关注

这不是又一篇"AI 做的 UI 很丑"的吐槽贴。它把 slop 当作可以精确诊断的视觉模式来对待——蓝紫渐变、发光玻璃卡片、同色系状态框、emoji 点缀、默认语义配色——每一条都有命名、有代码信号（grep 就能扫出来的 CSS 类名）、有清理方案。33 条覆盖了从"经典 slop"到"进化型 slop"的完整光谱，且全部用 HTML 重建了 before/after 对照。

实用价值：可以直接作为 Agent 编码时的 UI 约束 Skill 使用，也可以作为 Design Review 的检查清单。配套的 Skill 能从项目中扫描并清理 slop 模式。
