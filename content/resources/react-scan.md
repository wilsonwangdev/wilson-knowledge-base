## 一句话总结

基于 stats.js 的 React 组件性能可视化工具，实时检测 re-render 频率和耗时，提供数据供 AI 进行针对性优化。

## 为什么关注

React 性能问题的根因定位耗时。React Scan 把 re-render 行为变成可视化的帧率面板（类似游戏开发中的 FPS 监控），可直接集成到开发环境或作为 AI Agent 的性能分析输入。相比 React DevTools Profiler 更轻量且实时。
