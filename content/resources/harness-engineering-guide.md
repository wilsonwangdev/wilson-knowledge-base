## 一句话总结

一本系统化的 Agent 工程学在线指南，覆盖从 prompt 设计到多 Agent 协作的完整知识体系，以 GitBook 形式组织，结构清晰、持续更新。

## 核心内容

- Agent 基础架构设计
- Prompt Engineering 方法论
- Tool Use 与 Function Calling
- 记忆系统（短期 / 长期 / 向量）
- 多 Agent 协作与编排
- 评估与测试体系
- 生产部署与监控

## 为什么关注

市面上 Agent 资料散落在论文、博客、推文中，缺少成体系的中文梳理。这本指南把 Agent Engineering 当作一门工程学科来组织，每章有理论、有代码示例、有实践 check list，适合作为 Agent 开发者的案头参考。
