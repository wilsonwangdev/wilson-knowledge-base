## 一句话总结

面向 Design Engineer 的 Agent Skill 精选目录——涵盖 accessibility 审计、动画性能优化、metadata 修正、UI 基线约束等类别，每个 Skill 都有复制即用的安装命令。

## 为什么关注

这本质上是「UI 品质保障的 Agent Skill 市场」。核心贡献者 @ibelick（Interface Office）提供了最有价值的几个 Skill：
- **baseline-ui**：在 Tailwind 项目中强制执行动画时长、字体比例、可访问性约束
- **fixing-accessibility**：按优先级（Critical → Low）逐层审计 ARIA、键盘导航、焦点管理
- **fixing-motion-performance**：检查 layout thrashing、compositor 属性、滚动动画性能

此外还有 @addyosmani 的前端 UI 工程 Skill、@shadcn-ui 的组件工作流 Skill、@vuejs-ai 全套 Vue 最佳实践。每个 Skill 都可以 `npx skills i` 一行安装。1.8k GitHub Stars。
